# Fitur yang Dibandingkan pada Kode Awal dan Kode Akhir

Tabel fitur yang setara pada kode awal dan kode akhir sebagai dasar perbandingan.

| Fitur | Kode Awal | Kode Akhir |
| --- | --- | --- |
| Layar pembuka dan pengantar (*onboarding*) | Ada | Ada |
| Beranda: masukan teks atau tautan, tombol deteksi, status layanan | Ada | Ada |
| Hasil: vonis, probabilitas, analisis, dan kata kunci SHAP serta LIME | Ada | Ada |
| Simpan dan batal simpan ke riwayat | Ada | Ada |
| Salin laporan hasil | Ada | Ada |
| Riwayat: lihat, buka kembali, hapus | Ada | Ada |
| Edukasi literasi digital | Ada | Ada |
| Sumber data riwayat berbasis berkas JSON (opsional) | Tidak ada | Ada, tidak aktif |
